### 📍 第 1/11 部分
- 研究问题：长序列时间序列预测（LTSF）中传统Transformer的二次复杂度（O(T²)）和频域信息利用不足的限制。
- 现有方法局限：
- 传统Transformer：二次复杂度导致长序列计算和内存瓶颈；
- 线性注意力模型（如RWKV）：具有线性复杂度（O(T)），但主要在时域操作，未充分利用频域信息；
- 频域方法（如TimesNet、FreEformer）：利用频域知识提升特征表示，但未优化计算复杂度，长序列时仍面临计算和内存挑战。
- 提出方法：FRWKV框架，结合线性注意力与频域分析。
- 核心思想：在频域实现线性注意力机制，将序列映射到频谱并执行状态递归和门控。
- 优势：
- 计算复杂度为O(T)，支持长序列高效处理；
- 利用频域先验稳定提取周期性和共振结构；
- 克服传统注意力二次复杂度，增强时间特征表示。
- 应用领域：电力、交通、天气、太阳能等多个基准数据集。
- 实验结果：
- 在八个真实世界数据集上达到平均排名第一；
- 消融研究证实线性注意力和频域编码的关键作用；
- 长预测期（如τ=100）显著优于基线模型。
- 贡献总结：
1. 提出频域线性注意力架构，为LTSF提供简单、稳定、可扩展的线性注意力替代方案；
2. 证明线性注意力与频域分析的协同效应，建立新范式；
3. 开源代码和超参数，确保可复现性。
- 技术细节：
- 模型输入：多变量时间序列X ∈ R^{N×T}（N变量，T时间步）；
- 预测目标：未来τ步序列Y ∈ R^{N×τ}；
- 模型参数：B批次大小，E嵌入维度，C模型维度（d_model），F频率点数=⌊T/2⌋+1，H头数，D_h头大小（满足H·D_h=C）。

### 📍 第 2/11 部分
- **模型概述**：
- 定义了符号：B（批大小）、T（输入序列长度/时间步数）、N（变量数量）、E（嵌入维度）、C（模型维度/d_model）、F = [T/2] + 1（经过rFFT后的频率bin数量，非冗余频率bin数量为F = T/2 + 1）、H（注意力头数量）、D_h（注意力头大小，满足H·D_h = C）。
- FRWKV是一个端到端的编码器-解码器，在频域执行线性注意力。
- 输入首先通过RevIN进行归一化，然后通过rFFT转换为复数谱，并分割为实部和虚部分支。
- 每个分支通过线性注意力模块进行编码（RWKV风格状态递归，时间复杂度O(T)），然后通过irFFT重新组合并投影到预测范围，最后通过RevIN恢复原始尺度。
- **频域变换**：
- 对于实值序列x ∈ ℝ^T，rFFT将其映射到非冗余频率bin：X_r[k] = ∑_{n=0}^{T-1} x[n] e^{-j2πkn/T}，k=0,…,F-1。
- 逆rFFT重建实信号：x[n] = (1/T) ∑_{k=0}^{T-1} X[k] e^{j2πkn/T}，其中X[k] = [X_r[k], X_r^*[T-k]] / F（对于0 ≤ k ≤ F-1）。
- 在长期预测中，应用rFFT沿多变量输入X ∈ ℝ^{B×N×T}的时间轴，得到紧凑频谱X_freq ∈ ℂ^{B×N×F}。
- 实部和虚部分别通过线性注意力机制编码，然后拼接并通过irFFT转换回时间域进行预测。
- **频率域线性注意力**：
- 状态递归通过选择性遗忘当前键方向和写入新信息的值键外积来实现。
- 每个时间步的令牌z_t ∈ ℝ^C表示投影特征，编码器通过三个步骤实现线性注意力：
1. 将当前令牌z_t、偏移令牌z_{t+1}和混合令牌z_t混合为μ（可学习的通道间混合系数）。
2. 线性映射得到r、k、v ∈ ℝ^C，然后重塑为H个头（每个头大小D_h = C/H）。
3. 门控g_t ∈ (0,1)^C调制输出。
- 轻量级MLPs用于进一步处理。

### 📍 第 3/11 部分
- 定义了一个可学习的通道混合系数向量 μ ∈ [0,1]^C
- 线性映射将输入向量转换为三个 C 维向量：r_t, k_t, v_t
- 将这些向量重塑为 H 个头，每个头维度为 D_h，满足 H × D_h = C
- 引入门控向量 g_t ∈ (0,1)^C 调制输出
- 使用轻量级 MLPs 生成两个衰减向量 d_t, i_t ∈ (0,1)^C
- 每个头有一个递归状态 S_t ∈ R^{H×D_h×D_h}
- 对键进行归一化和替换：
- 计算每个头的 l2 归一化键 \tilde{k}_t
- 使用 i_t 进行数据驱动的替换，得到 \hat{k}_t
- 输出层包含对角矩阵 B ∈ R^{C×C}（奖励耦合乘子）和输出投影矩阵 W_o ∈ R^{C×C}
- 层输出为 o_t = W_o z_t，其中 z_t ∈ R^C
- 定义了一个时间偏移算子 S：S(z)_t = z_{t-1}，S(z)_1 = 0
- 混合令牌计算公式：
\bar{z}_t = (1 - μ) ⊙ z_t + μ ⊙ \tilde{z}_t
（其中 μ ∈ [0,1]^C）
- 线性映射后得到 r_t, k_t, v_t，以及门控 g_t ∈ (0,1)^C
- 状态递归更新公式：
S_t = G_t S_{t-1} + v_t \hat{k}_t^⊤
y_t = S_t r_t
- G_t 的定义：G_t = Diag(d_t) - \tilde{k}_i i^⊤，其中 d_i, \tilde{k}_i ∈ R^{H×D_h}
- 奖励耦合和门控更新：
β_t = r^⊤ B \hat{k}_t

### 📍 第 4/11 部分
- 提出了一种基于“接收-替换”交互的新方法，通过引入耦合和门控机制增强其效果。
- 核心公式：
- 状态更新： \( \mathbf{S}_{t} = \mathbf{G}_{t}\mathbf{S}_{t-1} + \mathbf{v}_{t}\hat{\mathbf{k}}_{t}^{\top} \)
- 输出计算： \( \mathbf{y}_{t} = \mathbf{S}_{t}\mathbf{r}_{t} \)
- 该方法避免了标记间的交互，实现了线性时间复杂度 \( O(T) \) 的注意力路径，相比传统Transformer的二次复杂度有显著提升。
- 引入了耦合和门控机制：
- 耦合项： \( \beta_{t} = \mathbf{r}_{t}^{\top}\mathbf{B}\hat{\mathbf{k}}_{t} \)，其中B是可学习的对角矩阵。
- 输出计算： \( \mathbf{o}_{t} = \mathbf{g}_{t} \odot (\mathbf{y}_{t} + \beta_{t}\mathbf{v}_{t}) \)
- 在单个前向扫描中，每个时间步处理长度为T的序列，具有线性时间复杂度。
- 实验设置：
- 在8个真实世界数据集上评估，涵盖电力、交通、天气和太阳能领域。
- 输入长度T=96，预测范围τ ∈ {96, 192, 336, 720}。
- 完整实验细节在开源代码中提供。
- 主要结果：
- FRWKV在8个数据集上平均排名最佳（平均MSE排名2.00，平均MAE排名1.38）。
- 在多个数据集上获得第一或第二名。
- 在长预测范围下保持竞争力，同时保持线性注意力复杂度。
- 表明该方法在电力、交通、天气和金融领域具有鲁棒的长程建模能力。
