# GDSR高分辨率遥感图像超分辨率高效架构设计分析报告
## 1. 架构核心设计参数
### 1.1 整体结构
GDSR为双分支遥感图像超分辨率架构，以RWKV线性长程依赖建模模块与CNN残差卷积分支并行作为核心，搭配全局细节重建模块（GDRM）实现特征融合，输出满足公式：
$$I_{SR} = Up(GDRM(F_{D_g}, F_{D_d}) + F_S)$$
其中$F_S$为低分辨率输入提取的浅层特征，$F_{D_g}$为全局分支深层特征，$F_{D_d}$为细节分支深层特征，$Up(\cdot)$为上采样函数。
内部通道维度固定为96，标准配置包含4个全局提取组（RGEG）、4个细节提取组（RDEG）、1个GDRM模块。
### 1.2 分支模块细节
1.  **细节提取组（RDEG）**：由多个残差卷积块（RCB）串联组成，单RCB计算逻辑为$F_{1+1} = \alpha F_{1} + W_{1}(LeakyReLU(W_{0}F_{1}))$，其中$\alpha$为可学习缩放因子。
2.  **全局提取组（RGEG）**：基于RWKV变体R-RWKV块实现长程依赖建模，前向计算流程如下：
    $$R_c = F_{in} W_{R_c}$$
    $$K_c = F_{in} W_{K_c}$$
    $$V_c = \gamma(K_c) W_{V_c}, \gamma(\cdot)为平方ReLU激活函数$$
    $$F_{cm} = (\sigma(R_c) \odot V_c) W_{cm}, \odot 为逐元素乘法$$
3.  **全局细节重建模块（GDRM）**：输入包含局部细节特征$F_D \in \mathbb{R}^{H \times W \times C}$与全局上下文特征$F_G \in \mathbb{R}^{H \times W \times C}$，依次执行PSAM特征变换、特征拼接共享投影、Sigmoid加权融合操作，实现双分支特征互补。
## 2. 损失函数设计
采用双组多尺度小波损失，针对现有单尺度小波超分辨率方法子带孤立、多尺度纹理协调不足的问题，将子带划分为低频结构子带与聚合高频细节子带两组，强制跨分辨率频率一致性，在多尺度框架下利用小波层次特征优化空间域重建效果。
## 3. 训练与测试配置
1.  数据集：公开数据集包括AID（30类，训练集占比20%、验证集占比10%、测试集占比70%）、UCMerced（21类，945张训练图像、105张测试图像），自建RSSRD-QH数据集包含2224张训练图像、561张验证图像、2804张测试图像，覆盖三江源及青海湖周边7个县域。所有高分辨率图像尺寸为600×600或256×256像素。
2.  退化策略：采用双重退化模型（CDM）合成低分辨率图像，随机顺序叠加各向同性高斯模糊、运动模糊、多方法插值缩放、高斯噪声、JPEG压缩噪声。
3.  训练参数：从低分辨率图像随机裁剪64×64图像块，分别与对应×2、×3、×4缩放的高分辨率图像配对，批量大小为16，初始学习率1e-4，使用Adam优化器（β1=0.9, β2=0.99），第100轮学习率减半，共训练200轮。所有实验在NVIDIA A800 80GB GPU上基于PyTorch框架完成。
4.  评估指标：采用YCbCr色彩空间Y通道的PSNR、SSIM，以及基于AlexNet预训练特征的LPIPS作为量化评估标准。FLOPs计算输入张量尺寸为1×3×160×160，推理速度测试输入为300张3×160×160图像。
## 4. 消融实验结果
1.  分支数量消融：仅启用RGEG分支时×3任务PSNR为28.94dB、SSIM为0.7652；RDEG分支RCB数量增至12、RGEG分支R-RWKVB数量为6时，性能稳定为PSNR 29.03dB、SSIM 0.7688，对应参数量13.17M、FLOPs 338.73G、推理速度14.8FPS。RCB数量超过12后性能无提升，计算成本线性增长。
2.  网络深度消融：双分支共享深度从1增至10时，PSNR/SSIM从28.89/0.7633持续提升至29.05/0.7695，LPIPS从0.3565持续下降至0.3450；对应参数量从3.65M增至32.21M，FLOPs从94.06G增至828.07G，FPS从53.0降至5.6。
3.  基线架构替换消融：将RGEG分支替换为SwinIR的RTSB结构得到GDSR_TC，替换为MambaIR的ResidualGroup结构得到GDSR_MC，二者性能与效率均低于标准GDSR：GDSR_TC PSNR/SSIM为28.89/0.7633、LPIPS 0.3565、FPS7.6、参数量12.83M、FLOPs337.26G；GDSR_MC PSNR/SSIM为28.97/0.7663、LPIPS0.3514、FPS9.1、参数量13.99M、FLOPs350.35G。
4.  损失函数消融：采用双组多尺度小波损失配置相比基础L_rec损失，实现PSNR/SSIM显著提升，仅带来极小的LPIPS增量，在所有基于小波的超分辨率变体中取得最低LPIPS值。
## 5. 基准数据集性能结果
1.  AID数据集CDM退化场景：×2尺度PSNR31.81dB、SSIM0.8592、LPIPS0.2366；×3尺度PSNR29.05dB、SSIM0.7694；×4尺度PSNR27.39dB、SSIM0.7022，PSNR相比HAT高0.09dB，参数量仅为HAT的63%，FLOPs仅为HAT的51%，推理速度为HAT的3.2倍。30类地物场景测试中，GDSR在几乎所有类别上取得最优PSNR与SSIM，其中Parking、Playground场景PSNR相比HAT高0.13dB，Arch、DenseResidential等复杂场景同样取得最优结果。
2.  UCMerced数据集：×2尺度PSNR34.53dB、SSIM0.9354、LPIPS0.0918；×3尺度PSNR30.15dB、SSIM0.8500、LPIPS0.2057；×4尺度PSNR27.79dB、SSIM0.7683，12项评估指标中有7项为当前最优。
3.  RSSRD-QH数据集：bicubic退化场景下×2尺度PSNR29.87dB；CDM退化场景下×3尺度PSNR22.87dB、SSIM0.3864，×4尺度PSNR22.27dB、SSIM0.3488。
4.  跨方法横向对比：在CDM、Synthetic、Real三类退化场景下，GDSR性能全面优于Bicubic、SRCNN、EDSR、SRGAN、SwinIR、HAT、HAUNet、SPT、ConvFormerSR、MambaIR、FreMamba等公开基线超分辨率方法。

## 7. 附加测试与后续方向
1.  含条纹噪声遥感图像测试：未加入条纹噪声数据训练的原始GDSR无法去除传感器条纹；补充条纹噪声样本重新训练后，可实现条纹去除与场景细节恢复。
2.  实际场景验证：在青海省鼠洞影像真实场景下，GDSR可提升图像清晰度，提取地表纹理细节；可用于道路网络重建、景观细节提取任务。
3.  后续工作方向：简化参数结构提升推理效率；扩展至高光谱遥感超分辨率场景，平衡空间增强效果与光谱保真度；验证多时序、跨传感器遥感图像超分辨率适配性。
