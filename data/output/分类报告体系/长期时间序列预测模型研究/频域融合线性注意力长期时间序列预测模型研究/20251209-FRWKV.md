# 频域融合线性注意力长期时间序列预测模型研究单篇分析报告
## 1. 模型基础信息
提出FRWKV模型，面向长期时间序列预测（LTSF）场景开展研究。核心创新点为线性注意力机制与频域分析方法融合，解决传统Transformer长序列处理的O(T²)二次复杂度问题，实现O(T)线性复杂度注意力路径，通过频域操作强化时间特征表示能力。该模型在8个真实世界数据集上取得第一平均排名，消融研究验证线性注意力与频率编码器的关键作用，配套代码与超参数已公开发布，满足可复现性要求。
## 2. 符号定义与模型整体流程
### 符号定义
| 符号 | 含义说明 |
| ---- | ---- |
| B | 批大小 |
| T | 输入序列长度/时间步数 |
| N | 变量数量 |
| E | 嵌入维度 |
| C | 模型维度/d_model |
| F | 频率二进制数，即非冗余频率bins的数量，满足F = [T/2] + 1 |
| H | 注意力头数量 |
| D_h | 注意力头大小，满足H * D_h = C |
### 端到端流程
FRWKV为编码器-解码器架构，全流程在频域执行线性注意力：
1. 输入先经RevIN归一化处理
2. 通过rFFT转换为复数谱，拆分实部分支与虚部分支
3. 两个分支分别经RWKV风格状态递归编码，该环节时间复杂度为O(T)
4. 编码后结果通过irFFT重组，投影返回时间维度
5. 最终由RevIN恢复原始数据尺度
## 3. 频域变换规则
针对实值序列x ∈ ℝ^T，rFFT映射至F个非冗余频率bin的计算公式为：
$$X_r[k] = \sum_{n=0}^{T-1} x[n] e^{-j2\pi kn/T},\ k=0,...,F-1$$
irFFT补全谱信息后执行逆变换重建实信号，计算公式为：
$$x[n] = \frac{1}{T} \sum_{k=0}^{T-1} X[k] e^{j2\pi kn/T}$$
其中X[k]在0≤k≤F-1区间取值为X_r[k]，在F≤k≤T-1区间取值为共轭X_r[T-k]。
长期预测场景下，多变量输入X ∈ ℝ^{B×N×T}沿时间轴执行rFFT，得到紧凑谱X_freq ∈ ℂ^{B×N×F}；拆分后的实部、虚部分别通过线性注意力机制编码，合并后经irFFT与维度投影转换回时间域。
## 4. 频率编码器内部运算规则
线性注意力模块在频率编码器中执行选择性遗忘与新信息写入操作，运算逻辑分为三部分：
### Token移位与混合
定义移位算子S满足$\tilde{\mathbf{z}}_t = S(\mathbf{z})_t = \mathbf{z}_{t-1}$，其中$\tilde{\mathbf{z}}_1 = 0$；混合token计算公式为：
$$\bar{\mathbf{z}}_{t} = (1-\boldsymbol{\mu}) \odot \mathbf{z}_{t} + \boldsymbol{\mu} \odot \tilde{\mathbf{z}}_{t}$$
其中$\boldsymbol{\mu} \in [0,1]^C$为可学习通道混合系数。线性映射输出$\mathbf{r}_t$、$\mathbf{k}_t$、$\mathbf{v}_t \in \mathbb{R}^C$与门控量$\mathbf{g}_t \in (0,1)^C$，通过MLP生成逐通道衰减参数$\mathbf{d}_t$、替换强度参数$\mathbf{i}_t$。
### 状态递归更新
对键执行逐头ℓ₂归一化得到$\tilde{\mathbf{k}}_t$，结合$\mathbf{i}_t$实现数据驱动式替换操作；定义逐头递归状态$\mathbf{S}_t \in \mathbb{R}^{H \times D_h \times D_h}$，门控更新运算式为：
$$\mathbf{G}_{t} = \mathrm{Diag}\left(\mathbf{d}_{t}\right) - \tilde{\mathbf{k}}_{t}\mathbf{i}_{t}^{\top}$$
$$\mathbf{S}_{t} = \mathbf{G}_{t}\mathbf{S}_{t-1} + \mathbf{v}_{t}\hat{\mathbf{k}}_{t}^{\top}$$
$$\mathbf{y}_{t} = \mathbf{S}_{t}\mathbf{r}_{t}$$
该注意力路径时间复杂度为O(T)，区别于传统Transformer的二次复杂度。
### 额外耦合与门控机制
通过对角矩阵$\mathbf{B} \in \mathbb{R}^{C \times C}$实现接收-替换交互增强，耦合运算式为：
$$\beta_{t} = \mathbf{r}_{t}^{\top}\mathbf{B}\hat{\mathbf{k}}_{t}$$
最终层输出计算公式为：
$$\mathbf{o}_{t}=\mathbf{g}_{t}\odot\mathbf{W}_{o}(\mathbf{y}_{t}+\beta_{t}\mathbf{v}_{t})$$
该架构完全避免传统Transformer的token-token交互操作。
## 5. 公开实验设置
全部实验基于8个覆盖电力、交通、天气、太阳能领域的真实世界数据集开展，输入序列长度统一设置为96，预测时域设置为96、192、336、720共4组参数。
## 6. 核心性能指标
- FRWKV整体平均排名：MSE为2.00，MAE为1.38，在全部参评模型中排名第1
- 公开单数据集核心结果：
  - ETTm1：MSE 0.380（第1），MAE 0.385（第1）
  - ETTm2：MSE 0.272（第1），MAE 0.316（第1）
  - ETTh1：MSE 0.433（第2），MAE 0.430（第3）
  - ETTh2：MSE 0.368（第3），MAE 0.391（第1）
  - ECL：MSE 0.171（第2），对应MAE未完整公开
- 其余ECL、Exchange、Weather、Solar数据集的剩余10组指标取值范围为0.169~0.942，对应排名覆盖1~10区间，配套平均统计项已在对应数据集表格末尾标注。
## 7. 对比实验配置
公开对比基线模型包含FreTS、Crossfm.等，已披露部分基线结果：FreTS在ETTm1上MSE为0.407（排名8），MAE为0.415（排名8）；Crossfm.在ETTm2上MSE为0.757（排名10），MAE为0.610（排名10）。
## 8. 消融实验结果
表格3覆盖ETTh1、ETTm1、Weather共3个数据集，验证不同组件配置下的性能差异：完整模型（FR + LA）在所有数据集上MSE、MAE指标均为最低；移除频域处理（FR）或禁用线性注意力（LA）均会导致预测准确率下降。消融实验控制变量设置为：移除目标组件后替换为单层全连接层，保持输入输出维度完全一致，确保性能变化仅由被移除组件本身引发。
