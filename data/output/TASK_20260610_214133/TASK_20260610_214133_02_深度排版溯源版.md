# 最终深度分析研报

## 一、研究背景与核心结论总览

随着**2023年新《公司法》正式落地实施**，以及平台用工、关联企业连锁经营等新业态用工模式的快速普及，公司关联关系的法律认定已跨越公司法、劳动法两大独立调整领域，不同司法场景下的认定规则冲突、裁判尺度差异问题逐步凸显，成为商事审判、劳动争议审判领域的共性疑难问题^[1]^。

本研究基于现行有效法律条文、公开司法判例与前沿学术研究成果，按照完整逻辑路径展开分析：
1.  系统梳理两大法律体系下关联关系的法定界定标准、适用场景边界
2.  横向对比两套规则的核心规制逻辑差异
3.  结合典型裁判案例解析当前司法实践中的认定分歧成因
4.  最终提炼关联关系合规适用的风险提示与优化方向

研究成果将为市场主体**规范关联架构设计、规避法律合规风险**提供清晰指引。


## 二、两大法律体系下公司关联关系的制度基础与立法定位

### 关联关系制度在两大部门法体系下的规则差异
两类关联关系规则的制度逻辑完全分野，核心要素对比如下：

| 对比维度         | 公司法体系下的关联关系规则                                                                 | 劳动法体系下的关联关系规则                                                                 |
|------------------|------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| 核心制度基础     | 完全锚定**公司独立人格与股东有限责任两大核心立法基石**                                     | 完全锚定**劳动者权益倾斜保护的基本原则**                                                   |
| 核心立法定位     | 防范实际控制人、控股股东、董监高利用特殊关联纽带实施利益输送、掏空公司资产、逃废对外债务等违法行为，维护商事交易的公平性与债权人合法权益 | 防范集团企业、关联经营主体通过拆分用工架构、逆向劳务派遣、混同用工等方式，刻意转移用工责任、规避劳动保障法定义务 |
| 核心判定基准     | 以**“资本层面的控制关系”**为相关规则的底层设计逻辑核心                                       | 以**“实质经营控制与对劳动者的从属性管理关系”**为相关规则的底层设计逻辑核心                   |
| 整体制度导向     | 偏向于保护公司法人独立财产权与外部商事交易秩序的稳定性^[2]^^[3]^ | 偏向于保障劳动者的劳动报酬、工伤保障、社保缴纳等基本劳动权益，避免用人单位利用关联实体的独立法人外壳架空劳动法律规则^[4]^^[5]^ |


## 三、公司法视域下关联关系的法定界定规则与典型适用场景

# 公司法视域下关联关系的法定界定规则
依据新修订《中华人民共和国公司法》及配套司法解释征求意见稿的相关规定，关联方被明确定义为与公司存在特殊关系、可能使其获取不正当利益或损害公司利益的自然人、法人或其他组织，具体覆盖范畴如下：
- 直接/间接控制的股东
- 实际控制人
- 董事及高级管理人员
- 控股/参股关联公司
- 与控股股东存在重大经济利益关联的其他主体

其核心判定标准**以实质经营控制与利益关联属性为核心**，立法目的在于规制不当关联交易、保护中小股东与债权人的合法权益、维护资本市场公开公平公正秩序^[2]^。

其典型适用场景主要分为四类，具体如下：
1. **公司治理与关联交易纠纷场景**：法院核查股东是否滥用关联关系排挤小股东、转移公司利润的违规行为
2. **公司解散、清算类案件场景**：核验关联主体是否存在通过关联交易隐匿资产、逃废对外债务的行为
3. **法人人格否认规则适用场景**：针对关联公司受控于同一实际控制人时出现人格混同、过度控制、财产混同的情形，突破有限责任原则判令关联方承担连带清偿责任，当前新公司法规则进一步细化了直接控制关系和特定控制行为下的差异化追责标准，避免不当扩大无关关联方的责任边界^[3]^
4. **股东出资加速到期场景**：结合关联关系核查是否存在股东利用关联交易抽逃出资、逃避出资义务的情形，维护债权人的合法受偿权益^[1]^


## 四、劳动法视域下关联关系的法定界定规则与典型适用场景

# 劳动法视域下关联关系的法定界定规则
该规则**核心基于实质控制与劳动管理关联的判定标准**，重点核查是否存在关联公司通过多层嵌套架构规避用工法定责任的行为，**核心立法目标是保障劳动者合法权益，防止用人单位滥用关联关系拆分用工、转移资产逃避劳动报酬、工伤赔偿等法定责任**^[5]^。
其具体判断维度共涵盖四大核心层面，明细如下：
- 股权结构
- 共同控制人属性
- 财务交叉程度
- 管理一体化程度

## 典型适用场景
当前该规则的落地适用场景主要可分为四大类，各类场景下的裁判适用逻辑明确：
1. **逆向劳务派遣的认定场景**：针对母子公司等关联主体之间以逆向派遣形式转移劳动者、规避用工责任的行为，当前司法实践普遍认定该类规避行为无效，支持劳动者向关联关联主体主张连带权益^[4]^
2. **关联公司混同用工场景**：当存在多家关联公司交叉签订劳动合同、轮流指派劳动者、工资发放主体混同的情形，法院可直接认定关联公司共同承担用人单位的法定责任
3. **新业态用工关系认定场景**：针对平台关联公司通过设立多层运营主体、诱导骑手注册个体工商户等方式规避劳动关系认定的情形，从人身从属性、经济从属性、组织从属性三个核心维度判定真实用工关系属性，厘清平台关联主体的法定责任边界^[6]^
4. **劳动权益执行追偿场景**：当用人单位无财产可供执行时，若查明关联公司存在与用工主体财产混同、人员混同的情形，可追加关联公司对劳动者的薪资、工伤待遇等债权承担连带清偿责任^[2]^

除此之外，在两类延伸场景中也会涉及对关联关系下用工安排合法性的实质审查，避免用人单位利用关联架构损害劳动者法定权益^[7]^^[8]^：
- 超龄劳动者不完全劳动关系认定场景
- 隐形加班事实核查场景


## 五、两大法律体系下关联关系规制的核心差异维度横向对比

两大法律体系对公司关联关系的规制逻辑存在本质分野，核心差异可从四大维度清晰梳理：
1.  **立法初衷与保护法益层面的差异**
    公司法体系下关联关系规制的核心目标是刺破公司有限责任面纱，防范实际控制人利用关联主体转移资产、逃废债务，最终保护中小股东与外部债权人的合法权益；而劳动法体系下关联关系规制的核心目标是遏制企业利用多层关联架构拆分用工链条、规避法定用工责任，优先保障劳动者的劳动报酬、工伤保障等基本生存权益，二者的价值排序存在明确差异^[2]^^[9]^。
2.  **核心界定标准层面的差异**
    公司法维度对关联关系的认定主要以资本控制关系为核心基准，判断要素包括直接/间接持股比例、实际控制权归属、董监高人员交叉任职、财务账户混同等显性特征，规则边界相对清晰；劳动法维度对关联关系的认定则突破了资本关联的形式要件，核心以实质用工控制权、管理从属性为判断标准，即便不存在直接股权关联，只要多家企业统一调配人员、统一制定考勤考核规则、共享用工管理体系，即可被认定为劳动法层面的关联用工主体^[5]^^[2]^。
3.  **责任触发逻辑层面的差异**
    公司法下关联主体的连带追责必须以“人格完全混同、独立意志丧失”为前提，仅当存在明确证据证明关联公司之间边界完全模糊、实际控制人滥用独立法人地位损害债权人利益时，才会突破有限责任规则要求关联公司承担连带责任；而劳动法下的关联用工责任触发无需达到人格完全混同的标准，只要关联主体共同对劳动者实施了管理、共同从劳动者的劳动中获益，即需要对欠薪、工伤等用工损害承担法定连带责任，责任认定门槛显著更低^[3]^^[4]^。
4.  **举证责任分配层面的差异**
    公司法下主张关联关系存在并要求突破有限责任的债权人、中小股东需要承担完全举证责任，证明人格混同、过度控制等核心事实；而劳动法下劳动争议案件适用部分举证倒置规则，劳动者仅需初步证明存在关联企业混同用工的表象，由用人单位举证证明自身与关联主体的用工管理相互独立，否则将承担举证不能的不利后果^[2]^。

## 六、关联关系相关典型司法裁判差异案例梳理与裁判逻辑解析

当前司法实践中围绕**关联关系认定**已形成多类典型裁判差异案例，对应不同的裁判逻辑边界，具体可分为两大领域的裁判规则：

## 一、公司法领域的典型裁判案例
1.  新《公司法》实施后全国首起私募管理人高管追责案
    该案核心争议为《公司法》第一百九十一条下董事、高管的责任性质认定，不同法院对关联关系下的**连带责任与补充责任边界认定**存在裁判分歧，最终生效判决认定存在失职行为的私募管理人对投资人2000万元损失承担赔偿责任，明确了关联主体利用管理控制权损害投资人利益时的追责规则^[10]^。
2.  最高人民法院审理的(2026)最高法知民终96号专利侵权上诉案
    该案中原告提交关联公司的生产能力、技术研发资质证据，其关联关系仅用于证明自身具备专利实施能力，并未触发公司法下人格混同的追责规则，法院最终认可该类证据的效力，清晰区分了**知识产权案件中关联关系证据的辅助证明属性**与公司法关联追责规则的适用边界^[11]^。

## 二、劳动法领域的典型裁判差异案例
1.  外卖骑手同类用工模式的差异化认定案例
    两起案件中骑手均隶属于同一平台体系，法院依据不同的从属性特征作出差异化裁判，两类情形的认定规则对比如下：
    | 骑手类型 | 核心用工特征 | 裁判认定结果 |
    | -------- | ------------ | ------------ |
    | 全职专送骑手 | 完全接受平台统一考勤管理、固定发放劳动报酬 | 认定与平台存在法定劳动关系，支持其工伤认定申请 |
    | 众包骑手 | 可自主选择接单、自负盈亏 | 认定双方属于承揽合同关系，不存在法定劳动关系 |
    该裁判差异核心在于对**关联平台对劳动者的管理支配强度**的差异化判定标准把握^[6]^^[9]^。

2.  关联企业逆向劳务派遣无效认定判例
    法院明确认定母公司安排员工逆向派遣至子公司的行为属于关联企业利用用工架构规避法定责任的无效行为，将此类借助关联关系损害劳动者权益的用工模式纳入否定性评价范畴，符合当前主流审判趋势^[4]^。

3.  超龄劳动者不完全劳动关系认定判例
    在贺臻诉用工主体的(2025)沪0207民初16584号案件中，法院突破传统劳动关系认定的年龄限制规则，认定已达到法定退休年龄但尚未领取职工基本养老保险待遇的超龄劳动者与用工单位构成**不完全劳动关系**，判定关联用工主体对其工伤保险待遇承担全额赔付责任，明确了特殊劳动者群体的关联用工责任边界^[7]^。


## 七、关联关系合规适用风险提示与规范化优化方向

# 关联关系合规适用风险提示与规范化优化方向
可从两大法律体系维度分别梳理落地：

---

## 一、核心合规风险提示
1. **公司法领域风险**：随意利用关联关系开展利益输送、刻意制造多关联公司人格混同以逃避债务的行为，极易触发新公司法框架下的法人人格否认规则，导致股东、实际控制人需对公司对外债务承担连带清偿责任，当前配套司法解释征求意见稿已进一步细化关联公司人格混同的追责要件，相关违规行为的司法举证门槛已显著降低^[1]^。此外若关联交易未履行法定披露、内部决策程序，相关交易存在被认定为无效或可撤销的风险，同时需规避合规误区，不得仅基于普通关联关系就要求独立运营、无人格混同情形的关联公司无端承担非自身债务的连带清偿责任^[2]^。
2. **劳动法领域风险**：关联企业之间通过逆向劳务派遣、跨关联主体转嫁劳动关系、拆分用工架构等方式规避法定用工责任的操作，当前司法裁判已形成明确的无效认定倾向，劳动者权益受损时可向所有涉事关联公司主张连带赔偿责任，用工主体无法通过多层关联主体设计转嫁法定社保缴纳、加班工资支付、工伤赔偿等强制义务^[4]^。尤其是新业态用工场景下，随意通过多个关联主体分割用工管理权、将实质劳动关系包装为承揽合作关系的操作，极易被司法机关穿透认定为事实劳动关系，导致平台或关联主体需承担补缴社保、支付二倍工资差额等额外高额用工成本^[9]^。

---

## 二、规范化优化方向
1. **构建双维度关联关系台账管理制度**：分别基于公司法合规要求梳理所有关联主体的股权结构、资金往来、关联交易记录，基于劳动法合规要求梳理所有关联主体间的人员调动、用工混同情况，实现关联关系全链路可追溯、可核查，从源头规避不合规关联操作。
2. **建立关联交易与人员流转的前置合规审查机制**：所有关联交易需提前履行信息披露、股东会/董事会表决程序，关联主体间的人员调动、劳务派遣需明确用工主体责任边界，严禁通过关联架构恶意转嫁用工成本、逃避对外债务，实现两大法律体系下关联关系运营的合规闭环。
3. **定期开展涉关联关系的司法判例复盘工作**：结合最新的裁判尺度动态调整内部合规规则，针对法人人格否认、逆向劳务派遣、隐形加班认定等高频争议场景提前预设应对方案，最大化降低关联关系相关的诉讼风险与合规运营成本。
