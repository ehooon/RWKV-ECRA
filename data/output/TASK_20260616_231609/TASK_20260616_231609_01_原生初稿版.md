# 最终原生分析初稿

## 一、 Fable 5 禁用事件全局执行摘要

2026年6月9日，Anthropic正式发布Fable 5和Mythos 5两款大语言模型，其中Fable 5面向全球公开，Mythos 5仅向受信任合作伙伴开放^[WEB_REF_BD_060a06]^[WEB_REF_BD_a96837]^。然而仅仅三天后的6月12日，美国商务部工业安全局（BIS）以出口管制为法律工具，要求Anthropic立即停止向所有非美国公民提供Fable 5和Mythos 5——包括在美国持签证工作的外国人，甚至Anthropic自家的外籍员工^[WEB_REF_BD_3ab86c]^[WEB_REF_BD_1e0e66]^。官方说辞是一个叫Pliny的团队在Fable 5发布后48小时内绕过了其安全系统（"越狱"），美国政府以此为由启动出口管制^[WEB_REF_BD_3ab86c]^。但Anthropic回应称，Pliny越狱后找到的漏洞都是"已知的、不严重的小问题"，GPT-5.5不越狱也能做到同样的事^[WEB_REF_BD_3ab86c]^[WEB_REF_BD_1e0e66]^。

此次禁用是AI史上第一次已部署给数亿人的商业大模型被政府强制召回^[WEB_REF_BD_fad22e]^[WEB_REF_BD_1e0e66]^。Fable 5在14项基准测试中拿下12项第一，其ExploitBench（AI漏洞发现能力测试）得分78分，是Opus 4.8（40分）的近两倍；Mythos Preview在50家合作机构系统中找出了超过10,000个高危零日漏洞，效率是人类的几十倍^[WEB_REF_BD_3ab86c]^[WEB_REF_BD_2a05da]^。这意味着Fable 5不是"会写代码的AI"，而是"会找漏洞的AI"——其网络安全能力已超出美国政府愿意让非美国人接触的阈值^[WEB_REF_BD_3ab86c]^。

事件发生后，微软同日因数据安全顾虑内部禁用Fable 5^[WEB_REF_BD_fad22e]^[WEB_REF_BD_1e0e66]^。Anthropic发布声明表示服从但不认同^[WEB_REF_BD_fad22e]^[WEB_REF_BD_1e0e66]^。6月22日前Pro/Max/Team/Enterprise订阅用户可免费使用Fable 5，之后需单独购买usage credits，价格是Opus 4.8的两倍（输入$10/百万token，输出$50/百万token）^[WEB_REF_BD_a96837]^[WEB_REF_BD_ef8740]^。小米在智源大会上评价Fable 5是"中间状态产物"^[WEB_REF_BD_292cf2]^[WEB_REF_BD_54409f]^，并于6月13-14日开源MiMo Code V0.1.0加速国产替代^[WEB_REF_BD_54409f]^。此次事件标志着"AI有国籍了"，AI的能力本身已成为国家安全的边界线^[WEB_REF_BD_3ab86c]^[WEB_REF_BD_2a05da]^。
