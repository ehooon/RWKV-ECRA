# 最终深度分析研报

## 一、 Fable 5 禁用事件全局执行摘要

2026年6月9日，Anthropic正式发布Fable 5和Mythos 5两款大语言模型，其中Fable 5面向全球公开，Mythos 5仅向受信任合作伙伴开放^[1]^^[2]^。然而仅仅三天后的6月12日，美国商务部工业安全局（BIS）以出口管制为法律工具，要求Anthropic立即停止向所有非美国公民提供Fable 5和Mythos 5——包括在美国持签证工作的外国人，甚至Anthropic自家的外籍员工^[3]^^[4]^。官方说辞是一个叫Pliny的团队在Fable 5发布后48小时内绕过了其安全系统（"越狱"），美国政府以此为由启动出口管制^[3]^。但Anthropic回应称，Pliny越狱后找到的漏洞都是"已知的、不严重的小问题"，GPT-5.5不越狱也能做到同样的事^[3]^^[4]^。

此次禁用是AI史上第一次已部署给数亿人的商业大模型被政府强制召回^[5]^^[4]^。Fable 5在14项基准测试中拿下12项第一，其ExploitBench（AI漏洞发现能力测试）得分78分，是Opus 4.8（40分）的近两倍；Mythos Preview在50家合作机构系统中找出了超过10,000个高危零日漏洞，效率是人类的几十倍^[3]^^[6]^。这意味着Fable 5不是"会写代码的AI"，而是"会找漏洞的AI"——其网络安全能力已超出美国政府愿意让非美国人接触的阈值^[3]^。

事件发生后，微软同日因数据安全顾虑内部禁用Fable 5^[5]^^[4]^。Anthropic发布声明表示服从但不认同^[5]^^[4]^。6月22日前Pro/Max/Team/Enterprise订阅用户可免费使用Fable 5，之后需单独购买usage credits，价格是Opus 4.8的两倍（输入$10/百万token，输出$50/百万token）^[2]^^[7]^。小米在智源大会上评价Fable 5是"中间状态产物"^[8]^^[9]^，并于6月13-14日开源MiMo Code V0.1.0加速国产替代^[9]^。此次事件标志着"AI有国籍了"，AI的能力本身已成为国家安全的边界线^[3]^^[6]^。

## 三、 关键动态时间线与隐形条款

## 四、 Fable 5 能力全景：14项基准测试实证

### 基准测试表现
Fable 5 / Mythos 5在14项基准测试中拿下12项第一^[6]^。

- **编程领域**：SWE-Bench Pro上Fable 5得分80.3%，远超Opus 4.8的69.2%、GPT-5.5的58.6%和Gemini 3.1 Pro的54.2%^[6]^；FrontierCode (Diamond)上Fable 5得分29.3%，是GPT-5.5的5倍^[6]^。
- **终端能力**：Terminal-Bench 2.1中Fable 5得分88.0%，优于Opus 4.8的82.7%、GPT-5.5的83.4%和Gemini 3.1 Pro的70.7%^[6]^。
- **网络安全领域**：ExploitBench（AI漏洞发现能力测试）上Fable 5得分78.0%，是Opus 4.8（40.0%）的近两倍，也远超GPT-5.5的34%^[6]^[WEB_REF_BD_BD_2a05da]^。
- **知识工作**：GDPval-AA测试中Fable 5得1932分，高于Opus 4.8的1890分、GPT-5.5的1769分和Gemini 3.1 Pro的1314分^[6]^。
- **法律领域**：Legal Agent Benchmark上Fable 5得分13.3%，而GPT-5.5仅2.1%，Gemini为0.0%^[6]^。
- **生物医学领域**：BioMysteryBench (hard)上Fable 5得分46.1%，优于Opus 4.8的40.0%^[6]^。
- **医疗领域**：HealthBench Professional上Fable 5得分66.0%，优于Opus 4.8的56.9%^[6]^。


### 实际能力表现
- **代码迁移效率**：Stripe实测显示Fable 5在5000万行Ruby代码库中一天完成了原本一个团队两个月的代码迁移^[8]^^[2]^。
- **核心功能**：可直接截图逆向生成完整网页源码、解析科研图表提取精确数值^[1]^，支持百万级Token上下文输入、128K Token单次输出，并具备长会话持久记忆能力^[1]^。
- **漏洞发现能力**：Mythos Preview在50家合作机构系统中找出了超过10,000个高危零日漏洞，效率是人类的几十倍^[3]^。

这意味着Fable 5不是"会写代码的AI"，而是"会找漏洞的AI"，且找漏洞效率远超人类^[3]^。
